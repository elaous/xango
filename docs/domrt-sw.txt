package sw // import "github.com/elaous/gojiberry/domrt/sw"

Package sw lets a Go/WASM binary run as a browser service worker:
it runs in the ServiceWorkerGlobalScope (no DOM, event-driven), reachable
via js.Global() the same way a page's `self` is. wasm_exec.js only needs
globalThis/crypto/performance/TextEncoder/TextDecoder, all of which the
service worker scope provides, so the same Go WASM runtime that runs a page
also runs a service worker -- it just needs a JS bootstrap file that does
`importScripts('wasm_exec.js')` instead of a <script> tag, since a classic
service worker has no DOM to attach one.

FUNCTIONS

func CacheAddAll(cache js.Value, urls []string) error
    CacheAddAll wraps cache.addAll(urls).

func CachesMatch(request js.Value) (js.Value, bool)
    CachesMatch wraps caches.match(request), returning ok=false on a cache miss
    (not treated as an error).

func CachesOpen(name string) (js.Value, error)
    CachesOpen wraps caches.open(name).

func ClaimClients() error
    ClaimClients wraps self.clients.claim(), which lets an activating worker
    start controlling already-open pages immediately instead of only pages
    opened after this activation.

func OnActivate(fn func(ExtendableEvent))
    OnActivate registers the worker's activate handler.

func OnFetch(fn func(FetchEvent))
    OnFetch registers the worker's fetch handler.

func OnInstall(fn func(ExtendableEvent))
    OnInstall registers the worker's install handler.


TYPES

type Event struct {
	// Has unexported fields.
}
    Event wraps a raw JS event object common to every service worker
    lifecycle/fetch event.

func (e Event) Raw() js.Value
    Raw returns the underlying JS event, for anything this package doesn't wrap.

type ExtendableEvent struct{ Event }
    ExtendableEvent is install/activate: the browser waits for WaitUntil's
    work to finish before completing the lifecycle transition (e.g. finishing
    pre-caching before the worker installs).

func (e ExtendableEvent) WaitUntil(work func() error)
    WaitUntil extends the event's lifetime until work returns, via the event's
    real waitUntil(promise) -- work runs on its own goroutine so this call
    doesn't block the JS event loop.

type FetchEvent struct{ Event }
    FetchEvent is dispatched for every request this worker's scope controls.

func (e FetchEvent) Request() js.Value
    Request returns the raw JS Request object, suitable for passing straight to
    CachesMatch or fetch().

func (e FetchEvent) RespondWith(work func() (js.Value, error))
    RespondWith supplies the response for this request via the event's real
    respondWith(promise) -- work runs on its own goroutine so this call doesn't
    block the JS event loop.
