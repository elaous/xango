package html // import "github.com/elaous/gojiberry/domrt/html"

Package dom wraps browser DOM/canvas/WebGL objects (Document, Element, Window,
Context2D, Context3D, observers, drag-and-drop) as typed Go structs, each with a
Get/Call escape hatch onto the underlying js.Value for anything not covered by a
typed method.

TYPES

type Context3D struct {
	Context js.Value
}
    Context3D wraps a <canvas> element's WebGL rendering context
    (canvas.getContext("webgl2"), falling back to "webgl"). Get/Call cover
    anything without a typed method below -- WebGL's real surface is hundreds
    of methods and constants; this wraps the core pipeline (shaders, programs,
    buffers, textures, drawing) rather than reimplementing the whole spec
    speculatively.

    Constants (TRIANGLES, ARRAY_BUFFER, COLOR_BUFFER_BIT, ...) are exposed
    as methods that read the real value off the live context object
    (gl.Get("TRIANGLES")) instead of hardcoded Go integers, so they can't
    silently drift from whatever the browser actually defines.

func (c *Context3D) ARRAY_BUFFER() int
    ARRAY_BUFFER is the buffer target for vertex attribute data.

func (c *Context3D) ActiveTexture(unit int)
    ActiveTexture selects which texture unit (TEXTURE0, TEXTURE0+1, ...)
    subsequent BindTexture calls affect.

func (c *Context3D) AttachShader(program, shader js.Value)
    AttachShader attaches a compiled shader to program.

func (c *Context3D) BLEND() int
    BLEND is the Enable/Disable capability for blending.

func (c *Context3D) BindBuffer(target int, buffer js.Value)
    BindBuffer binds buffer to target (ARRAY_BUFFER/ELEMENT_ARRAY_BUFFER) for
    subsequent buffer calls.

func (c *Context3D) BindTexture(target int, texture js.Value)
    BindTexture binds texture to target (e.g. TEXTURE_2D) for subsequent texture
    calls.

func (c *Context3D) BufferDataFloat32(target int, data []float32, usage int)
    BufferDataFloat32 uploads data to the buffer currently bound to target
    (ARRAY_BUFFER/ELEMENT_ARRAY_BUFFER).

func (c *Context3D) BufferDataUint16(target int, data []uint16, usage int)
    BufferDataUint16 uploads data (typically element/index data) to the buffer
    currently bound to target.

func (c *Context3D) CLAMP_TO_EDGE() int
    CLAMP_TO_EDGE is the wrap mode that clamps texture coordinates to the edge
    texel.

func (c *Context3D) COLOR_BUFFER_BIT() int
    COLOR_BUFFER_BIT selects the color buffer for Clear.

func (c *Context3D) COMPILE_STATUS() int
    COMPILE_STATUS is the GetShaderParameter pname reporting shader compile
    success.

func (c *Context3D) CULL_FACE() int
    CULL_FACE is the Enable/Disable capability for face culling.

func (c *Context3D) Call(method string, args ...any) js.Value
    Call invokes a method not covered by a typed wrapper below.

func (c *Context3D) Clear(mask int)
    Clear clears the buffers selected by mask (an OR of *_BUFFER_BIT constants).

func (c *Context3D) ClearColor(r, g, b, a float64)
    ClearColor sets the RGBA color Clear uses when clearing the color buffer.

func (c *Context3D) CompileProgram(vertexSrc, fragmentSrc string) (js.Value, error)
    CompileProgram is a convenience wrapping the usual
    create-shader/compile/attach/link sequence for a vertex+fragment shader
    pair, returning the linked program or an error naming whichever shader (or
    the link step) failed and its info log.

func (c *Context3D) CompileShader(shader js.Value)
    CompileShader compiles shader's currently set source.

func (c *Context3D) CreateBuffer() js.Value
    CreateBuffer allocates a new buffer object.

func (c *Context3D) CreateProgram() js.Value
    CreateProgram allocates a new, empty program object.

func (c *Context3D) CreateShader(shaderType int) js.Value
    CreateShader allocates a new shader object of the given type
    (VERTEX_SHADER/FRAGMENT_SHADER).

func (c *Context3D) CreateTexture() js.Value
    CreateTexture allocates a new texture object.

func (c *Context3D) DEPTH_BUFFER_BIT() int
    DEPTH_BUFFER_BIT selects the depth buffer for Clear.

func (c *Context3D) DEPTH_TEST() int
    DEPTH_TEST is the Enable/Disable capability for depth testing.

func (c *Context3D) DYNAMIC_DRAW() int
    DYNAMIC_DRAW hints that a buffer's contents are changed often and used many

func (c *Context3D) Disable(cap int)
    Disable turns off a WebGL capability.

func (c *Context3D) DrawArrays(mode, first, count int)

func (c *Context3D) Enable(cap int)

func (c *Context3D) EnableVertexAttribArray(index int)

func (c *Context3D) FLOAT() int

func (c *Context3D) FRAGMENT_SHADER() int

type DataTransfer struct {
	Value js.Value
}
    DataTransfer wraps a drag event's dataTransfer object, carrying whatever
    data a drag operation is moving and the drop/drag-effect negotiation between
    source and target.

func (d *DataTransfer) DropEffect() string
    DropEffect returns the drop effect the target will use (e.g. "copy", "move",
    "link", "none").

func (d *DataTransfer) EffectAllowed() string
    EffectAllowed returns the set of drop effects the drag source permits.

func (d *DataTransfer) Files() []js.Value
    Files returns the raw File objects dropped (e.g. from a desktop file drag),
    if any -- empty for a drag that only carries setData values. Wrap each
    with browser.WrapFile to read its name/size/type or its contents -- see
    domrt/browser's File API.

func (d *DataTransfer) GetData(format string) string
    GetData retrieves the data stored under format by the drag source.

func (d *DataTransfer) SetData(format, data string)
    SetData stores data under format (e.g. "text/plain") for the drop target to
    read.

func (d *DataTransfer) SetDropEffect(effect string)
    SetDropEffect sets the drop effect the target will use.

func (d *DataTransfer) SetEffectAllowed(effect string)
    SetEffectAllowed sets the drop effects the drag source permits (e.g. "copy",
    "copyMove", "all").

type Document struct {
	Document js.Value

    Document wraps the browser's global document object. Get/Call cover anything
    without a typed method below, the same escape hatch as the rest of this

func GetDocument() *Document
    GetDocument returns the global document object.

func (d *Document) Body() *Element
    Body returns the <body> element.

func (d *Document) Call(method string, args ...any) js.Value
    Call invokes a document method not covered by a typed wrapper above.

func (d *Document) CreateElement(tag string) *Element
    CreateElement creates a new, unattached element with the given tag name.

    CreateElementNS creates a new, unattached element in the given namespace

func (d *Document) CreateTextNode(text string) *Element

func (d *Document) DocumentElement() *Element
    DocumentElement returns the root <html> element.

func (d *Document) Get(name string) js.Value
    Get returns a named property of document not covered by a typed getter above

func (d *Document) GetElementByID(id string) *Element
    GetElementByID returns the element with the given id.

func (d *Document) GetElementsByClassName(class string) []Element
    GetElementsByClassName returns every element with the given class.

func (d *Document) GetElementsByName(name string) []Element
    GetElementsByName returns every element with the given name attribute.

func (d *Document) GetElementsByTagName(tag string) []Element
    GetElementsByTagName returns every element with the given tag name.

func (d *Document) GetElementsByTagNameNS(namespace, tag string) []Element
    GetElementsByTagNameNS looks up elements by namespace and tag (e.g.
    SVG's "http://www.w3.org/2000/svg"). Unlike GetElementsBy{Tag,Class}Name,
    there is no non-namespaced getElementsByClassNameNS/getElementsByNameNS in
    the DOM -- those aren't real browser APIs, so this package doesn't pretend
    to wrap them.

type DomNode interface {
	JSValue() js.Value
	Get(name string) js.Value
	Call(method string, args ...any) js.Value
	GetID() string
	SetID(id string)
	GetClassName() string
	SetClassName(className string)
	GetTagName() string
	GetTextContent() string
	SetTextContent(text string)
	GetAttribute(name string) string
	SetAttribute(name, value string)
	AppendChild(child DomNode)
	RemoveChild(child DomNode)

	SetInnerHTML(html string)
	AddEventListener(event string, callback js.Func)
	RemoveEventListener(event string, callback js.Func)
	Set(name string, value any)
	Click()
	Focus()
	Blur()
	Hidden() bool
	SetHidden(hidden bool)
	BoundingRect() Rect
	ScrollIntoView(smooth bool)
	StyleProperty(name string) string
	SetStyleProperty(name, value string)
	Style() Style
	ClientWidth() int
	ClientHeight() int
	ScrollLeft() int
	SetScrollLeft(x int)
	ScrollTop() int

    DomNode is implemented by Element and every element type in this package
    that embeds it (CanvasElement, AnchorElement, ButtonElement, SelectElement,
    InputElement, ...), so code that only needs the common DOM operations can
    accept any of them interchangeably.

type Element struct {
	Element js.Value
}
    Element wraps a DOM Element/Node. Get/Call cover anything without a typed
    method below, the same escape hatch as the rest of this package.

    Element is also the base every more specific element type (CanvasElement,
    AnchorElement, ButtonElement, SelectElement, InputElement, ...) embeds
    to pick up the common methods below; use the As* cast helpers (AsCanvas,
    AsAnchor, ...) to obtain one of those from a plain Element.

func (e *Element) AddEventListener(event string, callback js.Func)
    AddEventListener registers callback for event on e.

func (e *Element) AppendChild(child DomNode)
    AppendChild appends child as e's last child.

func (e *Element) AsAnchor() *AnchorElement
    AsAnchor casts e to an AnchorElement, or returns nil if e isn't an <a>.

func (e *Element) AsButton() *ButtonElement
    AsButton casts e to a ButtonElement, or returns nil if e isn't a <button>.

type Window struct {
	Window js.Value

    AddEventListener registers fn for event and returns the js.Func backing it.
    Pass that same value to RemoveEventListener to unregister it later --
